GNU Guix System (AKA GuixSD) has a strict FOSS only policy, which prohibits proprietary programs from being introduced into the project.
Unfortunately for some prospecitve Guix users, this leaves the operating system unable to boot on some hardware.

# Building a Nonguix Installation Image

Thanks to the folks at [Nonguix](https://gitlab.com/nonguix/nonguix), we can add their guix channel, which includes the full `linux` kernel, `linux-firmware`, microcode, and other non-free packages that would never be added upstream. They even have an installation image you can download from their [releases page](https://gitlab.com/nonguix/nonguix/-/releases).

While installing GuixSD over the weekend, GNU Savannah was experiencing outages. This was a problem as the main Guix channel is hosted there. Luckily, there is an offical mirror hosted on [Codeberg](https://codeberg.org/guix/guix-mirror); however, I had to modify and rebuild the Nonguix installation image to use the mirror instead of Savannah.

If Savannah is online, you may skip the rest of this section and proceed to [Installing GuixSD](#installing-guixsd).

You can apply the following patch after cloning the Nonguix repo.

```sh
git apply guix-mirror.patch
```

Following the README, I built the image with the following command:
```sh
guix system image --image-type=iso9660 ./nongnu/system/install.scm
```

You may also need to override your channels for this to build, especially if the default Guix channel is unreachable.

Run `guix pull` to update your channels.

# Installing GuixSD

Installation is pretty straightforward. Just follow the prompts from the "graphical" installer. The installer may warn you about unsupported hardware; this is normal. Keep following the installation prompts until it asks to confirm the configuration before starting the install. DO NOT PROCEED PAST THIS PROMPT.

The installer automatically generates a configuration based on your answers in the prompt, but is unaware of Nonguix packages, so it installs `linux-libre` without intervention. Switch to tty3 by pressing `Ctrl+Alt+F3` (you may need to hold the Fn key as well on some laptops).

Use the target drive as the Guix store instead of the installation environment.

```sh
herd start cow-store /mnt
```

Copy over the channels file from the installation environment.

```sh
cp /etc/guix/channels.scm /mnt/etc
```

You may now install GuixSD at this point.

```sh
guix system init /mnt/etc/config.scm /mnt
```

Depending on your hardware, internet, and how reccently your image was built, this can take a long time. Go grab a drink, you may be here for a while.
